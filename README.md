# iKoalaWala Rumble Chat Actor Rig

This rig runs on [Rumble Chat Actor](https://github.com/thelabcat/rumble-chat-actor), which logs in and posts/moderates Rumble chat through undocumented internal endpoints. [Rumble's Terms](https://rumble.com/s/terms) require Rumble's prior written permission for automated software, and the author has requested it. See [rumble-chat-actor's README](https://github.com/thelabcat/rumble-chat-actor#readme) for details. No affiliation with Rumble.
